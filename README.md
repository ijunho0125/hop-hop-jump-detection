# hop-hop-jump-detection

웹캠과 **MediaPipe Pose**를 이용해 사용자의 점프와 앉기 동작을 실시간으로 감지하고, 이를 키보드 입력으로 변환하는 프로젝트입니다.

현재는 크롬 공룡 게임(Chrome Dino)을 몸으로 조작하는 것을 목표로 합니다.

- 점프 → `Space`
- 앉기 → `↓`
- 다시 일어서기 → `↓` 키 해제

---

## 프로젝트 소개

`hop-hop-jump-detection`은 카메라 영상에서 사람의 자세를 추정하고, 신체 랜드마크의 움직임을 분석하여 점프와 앉기 동작을 판단합니다.

MediaPipe Pose를 이용해 어깨, 골반, 무릎, 발목 등의 위치를 실시간으로 추적하며, 단순히 한 프레임의 자세만 보는 것이 아니라 **시간에 따른 신체 위치 변화**를 이용해 동작을 구분합니다.

전체 구조는 다음과 같습니다.

```text
웹캠
 ↓
MediaPipe Pose
 ↓
신체 랜드마크 추적
 ↓
동작 분석
 ├─ 점프 → Space
 └─ 앉기 → Down
 ↓
Chrome Dino 조작
```

---

## 주요 기능

### 점프 감지

어깨와 골반의 평균 Y좌표를 이용해 사용자의 몸 중심 높이를 계산합니다.

이전 프레임과 현재 프레임의 위치 변화를 이용해 위쪽 이동 속도를 계산합니다.

```text
이전 몸 위치
    ↓
현재 몸 위치
    ↓
위쪽 이동 속도 계산
    ↓
일정 속도 이상 + 기준 높이보다 상승
    ↓
JUMP
    ↓
SPACE 입력
```

점프가 감지되면 다음 코드가 실행됩니다.

```python
pyautogui.press("space")
```

---

### 앉기 감지

앉기 동작은 다음 두 가지 정보를 함께 사용합니다.

1. 몸 중심이 평상시보다 아래로 내려갔는지
2. 무릎 각도가 충분히 작아졌는지

MediaPipe Pose의 주요 랜드마크 번호는 다음과 같습니다.

```text
23 = 왼쪽 골반
24 = 오른쪽 골반

25 = 왼쪽 무릎
26 = 오른쪽 무릎

27 = 왼쪽 발목
28 = 오른쪽 발목
```

골반-무릎-발목 세 점을 이용해 무릎 각도를 계산합니다.

```text
서 있는 상태
골반
  ●
  |
  ● 무릎
  |
  ● 발목

약 170° ~ 180°
```

```text
앉은 상태

골반 ●
      \
       ● 무릎
      /
     ● 발목

무릎 각도 감소
```

앉기가 감지되면:

```python
pyautogui.keyDown("down")
```

다시 일어서면:

```python
pyautogui.keyUp("down")
```

이 실행됩니다.

따라서 사용자가 앉아 있는 동안 크롬 공룡도 계속 숙이고 있습니다.

## 점프 감지 원리

MediaPipe의 Y좌표는 화면 위쪽으로 갈수록 작아집니다.

따라서 사용자가 점프하면 몸 중심의 Y좌표가 감소합니다.

점프 상승 속도는 다음과 같이 계산할 수 있습니다.

```python
velocity = (previous_y - current_y) / dt
```

즉,

```text
위치 변화량
─────────
 시간
```

을 이용해 얼마나 빠르게 위쪽으로 움직이고 있는지 판단합니다.

프로그램에서는 단순히 위치만 확인하지 않고:

```text
빠르게 위로 이동
        +
기준 자세보다 실제로 높아짐
        ↓
      JUMP
```

두 조건을 함께 확인하여 오인식을 줄입니다.

---

## 앉기 감지 원리

앉기 동작은 몸 중심의 하강과 무릎 각도를 이용합니다.

```text
무릎 각도 감소
      +
몸 중심이 아래로 이동
      ↓
     DUCK
```

무릎 각도만 사용하면 걷거나 다리를 움직이는 것을 앉기로 잘못 판단할 수 있기 때문에 몸 전체의 높이 변화도 함께 확인합니다.

## 민감도 조절

환경이나 카메라 위치에 따라 감지 민감도를 조절할 수 있습니다.

### 점프 민감도

```python
JUMP_SPEED_THRESHOLD = 0.16
```

값을 낮추면 작은 점프에도 더 민감하게 반응합니다.

예:

```python
JUMP_SPEED_THRESHOLD = 0.12
```

반대로 오인식이 많다면 값을 높일 수 있습니다.

```python
JUMP_SPEED_THRESHOLD = 0.20
```

---

### 앉기 민감도

```python
DUCK_KNEE_ANGLE = 145
DUCK_DROP_THRESHOLD = 0.035
```

앉기를 더 빠르게 인식하고 싶다면:

```python
DUCK_KNEE_ANGLE = 155
DUCK_DROP_THRESHOLD = 0.025
```

처럼 조절할 수 있습니다.

## 핵심 아이디어

이 프로젝트의 핵심은 단순한 이미지 분류가 아니라 **신체 랜드마크의 시간에 따른 위치 변화를 분석하는 것**입니다.

```text
카메라 영상
    ↓
AI 자세 추정
    ↓
관절 좌표 추출
    ↓
좌표 변화량 계산
    ↓
동작 판단
    ↓
게임 입력
```

즉, 컴퓨터 비전과 실시간 동작 분석을 이용해 사용자의 몸 자체를 하나의 게임 컨트롤러로 사용하는 프로젝트입니다.
